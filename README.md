# 📊 SME Financial Feasibility Calculator & Interactive Guide

An intuitive, lightweight, and fully interactive single-page web tool built to help small business owners and startup founders calculate break-even points, evaluate unit economics, and receive automated smart financial recommendations without accounting clutter.

---

## 🚀 Key Features

- **No-Install & Offline Ready**: Built with pure HTML5, CSS3, and Vanilla JavaScript (zero external dependencies).
- **Core Educational Guide**: Clear, non-jargon explanations of Fixed Costs, Variable Costs, Contribution Margin, and Break-Even Analysis.
- **Interactive Financial Engine**: Real-time KPI dashboard calculating Contribution Margin, Break-Even Volume/Revenue, and Expected Net Profit.
- **Smart Advisory System**: Dynamic financial feedback warning against underpricing, negative margins, or insufficient safety buffers.
- **Visual Analytics**: Dynamic HTML5 Canvas chart displaying total revenue, total costs, fixed cost baselines, and the exact Break-Even point.

---

## 📂 File Structure

- `index.html`: Complete single-file application containing the user interface, business logic, styling, and interactive chart renderer.
